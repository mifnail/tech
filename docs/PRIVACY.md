## 2. Цели обработки

- Учёт занятий, оценок и посещаемости студентов
- Отправка уведомлений студентам через Telegram и MAX (при включении ботов)
- Экспорт ведомостей и отчётов

## 3. Обрабатываемые данные

| Категория | Примеры |
|-----------|---------|
| ФИО преподавателя | Фамилия, имя, отчество (из настроек) |
| ФИО студентов | Фамилия, имя, отчество |
| Учебные данные | Группы, предметы, оценки, посещаемость, расписание |
| Идентификаторы Telegram | `telegram_id` (привязка студента к боту) |
| Идентификаторы MAX | `max_id` (привязка студента к MAX-боту) |

## 4. Хранение данных

Все данные хранятся **исключительно локально** в файле `lessons.db` (SQLite) на устройстве пользователя. Приложение работает в режиме **offline-first**: серверный доступ не требуется, сетевые соединения не устанавливаются (за исключением запросов к API Telegram/MAX при включённых ботах).

## 5. Передача третьим лицам

Данные **не передаются** третьим лицам, за исключением:

- **Telegram Bot API** — при включении Telegram-бота в настройках (токен вводится пользователем)
- **MAX Platform API** — при включении MAX-бота в настройках (токен вводится пользователем)

При отключении ботов в настройках передача данных прекращается.
