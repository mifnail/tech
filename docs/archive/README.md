# Архив документации

Документы, которые описывают прошлые состояния проекта. Оставлены как история
решений — **не руководство к действию**. Актуальное состояние — в `README.md`,
`docs/SPECIFICATION.md` и `AGENT.md`.

| Файл | О чём | Почему в архиве |
|---|---|---|
| `PLAN-vanilla.md` | План доработок для vanilla-фронтенда (удаление сущностей, правка названий, формат даты, дубликаты, экспорт) | Все пункты выполнены; фронтенд `static/app.js` удалён в `95b5f9e` |
| `BRANCH-DIFF.md` | Сравнение веток `main` (vanilla) и `redesign` (React) | Ветки слиты, фронтенд один — сравнивать нечего |
| `REACT-INTEGRATION-PLAN.md` | План переноса всего функционала с vanilla на React | Перенос завершён, vanilla удалён |

История правок всё равно лежит в git: `git log --follow docs/archive/<файл>`.
