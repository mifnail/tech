## Перенос в исходный Flask / Android проект

1. Добавить `public/static/redesign.css` и `public/static/redesign.js` в папку `static/` исходного проекта.
2. В `templates/index.html` после существующей ссылки на `style.css` подключить `/static/redesign.css` как stylesheet.
3. Сразу после существующего скрипта `/static/app.js` подключить `/static/redesign.js` обычным script-тегом (не module).
4. Сохранить существующий механизм версионирования URL статики. Для локальных шрифтов также перенести `public/fonts` в доступный серверу каталог или оставить Google Fonts из CSS.
5. Не заменять `lessons.db` и не запускать `seed_db.py` или миграции. Проверить стандартные тесты исходного проекта и сборку WebView перед выпуском APK.

Визуальный слой заменяет разметку обзора и навигации, добавляет представления групп, предметов, календаря и отчётов. Оригинальные действия создания / изменения / удаления сущностей, двунаправленный цикл оценок, календарь создания занятий и подтверждения используются из исходного `App` без изменения файла. Экспорт с новой страницы отчётов скачивает существующий xlsx endpoint; исходный Android-шаринг остаётся в оригинальном коде.

## Предпросмотр в Next.js

Эта среда изначально содержит Next.js, а не Flask. Поэтому добавлен отдельный API-адаптер:

- Без `TEACHHELPER_API_URL` используются явно обозначенные демонстрационные данные. Они хранятся в JSON-файлах временного каталога, изолированных cookie-сессией, и не имеют отношения к рабочей базе пользователя.
- С `TEACHHELPER_API_URL` (адрес исходного Flask-сервера, без `/api`) API-запросы передаются ему с исходными методами и телом. Изменения в подключённом режиме выполняются штатным Flask API.
- Подключённую среду нельзя публиковать без имеющейся защиты доступа: сохраняйте авторизацию и сетевую изоляцию исходного приложения. Сам адаптер не добавляет новую систему аутентификации.
- Токены ботов, отправка сообщений и резервное копирование рабочей базы в деморежиме недоступны и не имитируют успешное выполнение.
- ExcelJS используется только для действительного xlsx-экспорта из демосессии; в исходный Python-проект переносить эту зависимость не нужно.

Демонстрационное расписание использует условную сетку времени. В подключённом режиме показывается исходный номер пары без выдуманных часов.
