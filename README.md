# Учет занятий — журнал преподавателя

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Privacy](https://img.shields.io/badge/Политика-приватности-green.svg)](https://mifnail.github.io/tech/PRIVACY.md)

Мобильный журнал преподавателя: группы, предметы, занятия, оценки и посещаемость,
экспорт ведомостей в Excel, уведомления студентов через Telegram и MAX,
автообновления из GitHub-релизов.
Занятия — вручную или через календарь расписания, без интернета.
Работает как Android-приложение (WebView) и как desktop-версия в браузере.

## Стек

- **Backend:** Python 3, Flask (REST API), SQLite (WAL)
- **Frontend:** Vanilla JS SPA + CSS, без фреймворков (оптимизировано под WebView)
- **Экспорт:** openpyxl (только `.xlsx`)
- **Боты:** только стандартная библиотека Python + certifi (long-polling в фоне, общий транспорт — `botcore.py`)
- **APK:** Buildozer (python-for-android, WebView bootstrap), сборка и подпись в GitHub Actions

## Возможности

### Журнал
- Группы, студенты, предметы, расписание (включая чёт/неч недели)
- Занятия: проведение, отмена (с предупреждением о числе оценок), замены, дубли в один день; пропущенные — задним числом, отменённые — убрать
- **Создание с датой:** «Начать занятие» → выбор предмета + календарь-сетка (прошлое + сегодня, будущее закрыто), результат показывает дату из базы
- Смежные занятия (назад/вперёд), кликабельные колонки-даты в ведомости

### Оценки и посещаемость
- Компактный 2-колоночный список на занятии (шапка/подвал ≤10% экрана)
- **Двусторонний перебор тапом:** правая половина строки — вперёд (`— → 0 → 5 → 4 → 3 → 2`), левая — назад
- Маркировка присутствия, средний балл, должники

### Экспорт и шаринг (Android)
- Ведомости и отчёты в `.xlsx` (PDF/CSV/ICS отключены)
- Нативный путь: сохранение в «Загрузки» через MediaStore + системная шторка «Поделиться»
- Защита от stale-кэша WebView: версионированные URL статики + `no-store`

### Telegram-бот «Мои оценки»
- Привязка по фамилии, команды `/grades`, `/today`, `/help`, `/unbind`
- Read-only: студент видит только свои оценки
- **Постоянная клавиатура** под полем ввода: Оценки / Сегодня / Помощь / Отвязать
- Токен вводится в Настройках приложения (BotFather → /newbot)
- Ссылка-приглашение: тап по названию бота в Настройках копирует `https://t.me/<username>` (по введённому токену) и открывает «Поделиться»

### MAX-бот
- Привязка по фамилии (значок 📨 в списке студентов)
- Команды: `/grades` (сводка + инлайн-кнопки), `/today`, `/schedule` (расписание на 7 дней),
  `/avg` (средний балл), `/debts` (долги), `/vedomost` (**личный** xlsx — только строка студента),
  `/help`, `/unbind`
- Кнопки под каждым ответом: callback-ряд + message-ряд (Расписание / Средний балл / Долги)
- **Пуши новых оценок** с дебаунсом 10 сек (уходит только устоявшаяся оценка)
- **Пуши об отменах/заменах** занятий группы
- **Вечерние напоминания** накануне занятий (17:00–19:00)
- **Привязка преподавателя** (`/teacher КОД` из Настроек): утренний дайджест в 7:00 + пуши о новых привязках студентов
- **Куратор группы** (код на странице группы): пуши оценок своей группы с дебаунсом 1 мин (с ФИО), групповая ведомость по `/vedomost`
- Токен вводится в Настройках (@MasterBot → /create)
- Ссылка-приглашение (статичная): тап по названию бота в Настройках копирует ссылку и открывает «Поделиться»

### Бэкап
- Выгрузка `lessons.db` в «Загрузки», восстановление последней копии без выбора файла (выбор мёртв в WebView) или файлом на десктопе
- Перед заменой — автобэкап текущего, проверка файла, чекпоинт WAL
- Внимание: копия содержит токены ботов и привязки — не пересылать
- Проверка файла при восстановлении: SQLite-заголовок, обязательные таблицы (+ `schedule` для восстановления через бота), минимум 100 байт, `PRAGMA quick_check`
