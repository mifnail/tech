# TeachHelper4 — журнал преподавателя (LessonTracker)

Мобильный журнал преподавателя: группы, предметы, занятия, оценки и посещаемость,
экспорт ведомостей в Excel, уведомления студентов через Telegram и MAX.
Работает как Android-приложение (WebView) и как desktop-версия в браузере.

## Стек

- **Backend:** Python 3, Flask (REST API), SQLite (WAL)
- **Frontend:** Vanilla JS SPA + CSS, без фреймворков (оптимизировано под WebView)
- **Экспорт:** openpyxl (только `.xlsx`)
- **Боты:** только стандартная библиотека Python + certifi (long-polling в фоне)
- **APK:** Buildozer (python-for-android, WebView bootstrap), сборка и подпись в GitHub Actions

## Возможности

### Журнал
- Группы, студенты, предметы, расписание (включая чёт/неч недели)
- Занятия: проведение, отмена (с предупреждением о числе оценок), замены, дубли в один день
- **Создание задним числом:** «Начать занятие» → выбор даты (прошлое + сегодня, будущее запрещено), защита от дублей
- Смежные занятия (назад/вперёд), кликабельные колонки-даты в ведомости

### Оценки и посещаемость
- Компактный 2-колоночный список на занятии (шапка/подвал ≤10% экрана)
- **Циклический перебор тапом:** правая половина строки — вперёд (`— → 0 → 5 → 4 → 3 → 2`), левая — назад
- Маркировка присутствия, средний балл, должники

### Экспорт и шаринг (Android)
- Ведомости и отчёты в `.xlsx` (PDF/CSV/ICS отключены)
- Нативный путь: сохранение в «Загрузки» через MediaStore + системная шторка «Поделиться» (cast `Uri→Parcelable`, без chooser — работает на всех проверенных устройствах)

### Telegram-бот «Мои оценки»
- Привязка по фамилии, команды `/grades`, `/today`, `/help`, `/unbind`
- Read-only: студент видит только свои оценки
- Токен вводится в Настройках приложения (BotFather → /newbot)

### MAX-бот
- Привязка по фамилии (значок 📨 в списке студентов)
- **Пуш новых оценок** сразу после выставления
- Сводка по команде, **вечерние напоминания** накануне занятий (17:00–19:00)
- Токен вводится в Настройках (@MasterBot → /create)

## APK: сборка и установка

- Сборка — только через GitHub Actions (`.github/workflows/build-apk.yml`):
  тесты → Buildozer → подпись `apksigner` (ключ `release.keystore`, JKS-конверсия в CI) → артефакт
- Версия автоинкремента `0.<номер запуска>`, до 5 попыток при обрывах сети
- Перед установкой новой сборки старую версию удалить (конфликт ключей подписи у самых первых сборок)

## История (по коммитам, июль → сентябрь 2026)

1. **CRUD и база:** студенты/группы/предметы, FK, WAL, защита `lessons.db`
2. **Журнал:** расписание, дубли занятий, смежные занятия, отмены
3. **Мобильный UI:** 2-колоночная посещаемость, компактность, скролл-фиксы WebView
4. **Экспорт:** только Excel → нативное сохранение → шаринг (серия итераций: ClipData → cast → chooser-матрица → прямой `startActivity`)
5. **CI/APK:** подпись релизов, автобилд, ретраи, `et_xmlfile` для openpyxl
6. **Боты:** Telegram read-only → MAX с пушами и напоминаниями
7. **Удобство:** задние числа, двусторонний перебор оценок, кнопка «Поделиться» вместо Excel

## Предложения по развитию

1. **Финализировать шаринг:** оставить победивший вариант, добавить шаринг отчёта со страницы отчётов (там пока старая кнопка Excel)
2. **Импорт студентов из Excel** — загрузка списка группы файлом вместо ручного ввода
3. **Аналитика:** динамика среднего балла, список должников с порогом, тренды по студентам (CSS-полосы, без тяжёлых библиотек)
4. **Бэкап/восстановление БД** — выгрузка `lessons.db` в «Загрузки» и импорт обратно
5. **PIN-блокировка** приложения (журнал на личном телефоне)
6. **MAX:** отправка ведомости файлом, кнопки в сообщениях
7. **Поиск по журналу** (студент, дата, предмет одним полем)
8. **Семестровое архивирование** — закрытие семестра со срезом ведомостей
9. **Тёмная тема**
10. **Напоминания преподавателю** — «завтра 3 занятия, ведомости не заполнены»
