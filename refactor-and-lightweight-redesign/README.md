# TeachHelper — лёгкий веб-интерфейс

Самостоятельная React/Vite-реализация редизайна журнала из https://github.com/mifnail/tech. Исходный Flask-проект, SQLite-база, боты и APK не изменялись и не подключены. Это не рефакторинг Python-сервера и не опубликованный коммит в указанном репозитории.

## Что работает

- Обзор учебного дня, недельный календарь, расписание.
- Создание занятий с проверкой даты и времени, завершение и отмена.
- Двухколоночный журнал: нажатие справа меняет оценку вперёд, слева — назад. Массовая отметка присутствия.
- Создание/редактирование групп, добавление и поиск студентов.
- Поиск предметов и переход к отфильтрованному расписанию.
- Отчёты с фильтром группы/месяца, настоящий XLSX-экспорт.
- Профиль, JSON-резервные копии и восстановление с проверкой формата.
- Локальное сохранение с сообщением об ошибке, если хранилище недоступно.

Начальные данные демонстрационные: учебный день — 14 сентября 2026 года. Учебные планы предметов являются примерами. Переключатель семестра отображает выбранный учебный контекст, но не разделяет локальную базу на семестры.

При отмене занятия отметки сохраняются (об этом сообщает подтверждение). Это отличается от серверного сценария исходного проекта, где отмена удаляет оценки.

## Лёгкий дизайн

Системные шрифты, локальные SVG-иконки и одна небольшая SVG-иллюстрация. Нет видео, внешних изображений, эффектов размытия, анимационных библиотек или фоновых запросов. Адаптивность проверена от 320 до 1440 px. Экспорт запускается только по запросу пользователя; singlefile-сборка встраивает его код в основной HTML.

## Android 7+

`public/legacy.js` — классический IIFE-бандл с целью Chromium 51 и выборочными полифиллами. Загрузчик выбирает его в Chromium <107 и браузерах без модулей. CSS содержит fallback без Grid и без flex-gap. Базовый интерфейс не зависит от новых CSS-возможностей Tailwind.

Совместимость с реальным Android 7 / встроенным WebView и нативным скачиванием через MediaStore не проверялась. Проверка user-agent в современном Chromium проверяет выбор legacy-бандла, но не заменяет тест на устройстве. Для APK потребуется интеграция с исходным Android-мостом скачивания/резервного копирования.

После изменения исходников пересоберите обе версии:

1. `npx tsc --noEmit`
2. `node scripts/build-legacy.mjs`
3. `npm run build`

Готовые файлы: `dist/index.html` и `dist/legacy.js`. Не удаляйте legacy.js при публикации. `npm run build` самостоятельно не регенерирует public/legacy.js; готовая совместимая версия включена в проект.

## Проверка

- `npm run preview -- --host 0.0.0.0`
- В другом терминале: `node scripts/check-ui.mjs`

Playwright проверяет сохранение оценок, создание/поиск группы, экспорт XLSX, мобильную навигацию, загрузку legacy-версии и отсутствие горизонтального переполнения на шести ширинах.

## Структура

- `src/data.ts`: типы, демонстрационные данные, загрузка сохранённого журнала.
- `src/components/Icon.tsx`: маленький переиспользуемый набор SVG.
- `src/App.tsx`: экраны, формы и действия журнала.
- `src/index.css`: базовая адаптивная вёрстка.
- `src/refinements.css`: компактная десктопная компоновка и читаемость.
- `src/legacy.tsx`, `src/legacy.css`: совместимость старого WebView.
- `scripts/build-legacy.mjs`: сборка совместимого JS.
- `scripts/check-ui.mjs`: браузерные проверки.

Данные хранятся только в localStorage текущего браузера. JSON-копия этой версии не совместима с lessons.db. Для интеграции с исходным проектом необходимо заменить локальные операции на вызовы проверенных Flask API и провести регрессионные тесты исходного проекта.
