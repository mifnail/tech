# mifnail // engineering — редизайн

Адаптивный сайт услуг 3D-сканирования, реверс-инжиниринга и метрологии.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
```

## Сборка

```sh
npm run build
```

Готовый сайт находится в `dist/`. Загрузите содержимое этой папки на статический хостинг (например, GitHub Pages). Открывать рекомендуется через HTTP, а не через file://.

В архиве папка `ready-to-publish/` содержит готовую сборку, а `source/` — исходный проект. Для публикации на mifnail.github.io загрузите содержимое ready-to-publish в корень репозитория GitHub Pages.

## Возможности

- Адаптивная навигация и якорные переходы.
- Переключение визуальных режимов иллюстрации детали (это не интерактивный 3D CAD-просмотрщик).
- Фильтры примеров задач и модальные карточки с описанием.
- Выбор услуги и контактная форма.
- Копирование email и ссылка на Telegram.
- Ссылка на ZIP-архив проекта в подвале.

## Отправка заявки

Серверная часть не требуется. Форма подготавливает письмо через mailto: и открывает почтовый клиент пользователя. Пользователь самостоятельно отправляет письмо, при необходимости прикрепляя файлы. Если почтовый клиент не настроен, доступна связь через Telegram. Сайт не сохраняет данные формы.

Контакты: mifnail@yandex.ru, https://t.me/mifnail

## Контент и изображения

Базовая информация и контакты взяты с исходного сайта https://mifnail.github.io/. Иллюстрации созданы для редизайна и находятся в public/images/. Карточки показывают примеры инженерных задач, а не подтверждённые кейсы. Шрифты Golos Text и IBM Plex Mono загружаются из Google Fonts; без сети используются системные шрифты.

Основные файлы: src/App.tsx (структура и логика), src/index.css (оформление), index.html (метаданные).
