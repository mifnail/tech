## Рабочие правила, проверенные на практике

- `lessons.db` и любые `*.db` — персональные данные студентов. Из репозитория
  сняты (`a730fdb`), в `.gitignore`. Никогда не `git add -A` / `commit -a`.
- `dist/index.html` собирается вручную (`npm run build`) и коммитится —
  CI его не собирает.
- APK собирается только в GitHub Actions (`buildozer.spec`,
  `source.exclude_dirs` — 16 каталогов, мусор не тащим).
- Тесты: `python -m pytest tests/ -q` (524+), фронт — `npx playwright test`,
  `node --test tests/*.cjs`.
- Локальный стенд: Flask на свободном порту с копией базы во `%TEMP%`;
  фоновый сервер в песочнице получает readonly на БД — запускать
  с отключённой песочницей.
- `Test stand` в CI красный с момента появления (13.10) и никогда не был
  зелёным — это не регрессия; логи требуют прав администратора репозитория.
